# Sistema de Gestão - Pizzaria Manoel

## Status do projeto
Em desenvolvimento

## Tecnologias aplicadas
- Java (Lógica de Programação e Orientação a Objetos)
- Java Swing (Interface Gráfica)
- MySQL Workbench (Banco de Dados Relacional)
- JDBC e Padrão DAO (Conexão e Persistência de Dados)
- Git e GitHub (Versionamento de Código)

## Time de desenvolvedores
- Samuel Hernani Nascimento da Silva

## Objetivo do software
Automatizar e gerenciar o processo operacional da Pizzaria Manoel, permitindo um controle eficiente do registro de clientes, gestão do cardápio e lançamento de pedidos através de uma interface desktop intuitiva ligada a um banco de dados real.

## Funcionalidades do sistema (Requisitos)
- Cadastro de Clientes (Nome, Telefone, Endereço).
- Cadastro de Produtos com aplicação de Herança (Pizzas e Bebidas).
- Criação de Novos Pedidos, vinculando clientes e calculando o valor total de forma dinâmica.
- Interface Gráfica (GUI) funcional com navegação entre telas.
- Persistência e leitura de dados diretamente no banco de dados MySQL.
